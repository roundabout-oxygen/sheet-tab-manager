# Sheet Tab Manager(Chrome拡張機能)

Google スプレッドシートの
- 下部の通常タブを**タブ色で全面塗り**にし、
- 画面右側に**ドラッグで動かせる縦型のシート一覧ウィンドウ**(非表示シートも含む)を表示し、並び替え・表示/非表示・コピー・削除・名前変更・色変更を行えるようにします。

## セットアップ(初回のみ・約10分)

シートの一覧取得や非表示の切替には Google Sheets API(OAuth)を使います。拡張機能IDは `manifest.json` の `key` で固定されており、**`nkdgcnlckgfepbaadamalcdjdlajageh`** です。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「APIとサービス → ライブラリ」で **Google Sheets API** を有効化
3. 「OAuth 同意画面」を設定(ユーザーの種類: 外部)。スコープに `.../auth/spreadsheets` を追加し、自分のGoogleアカウントを「テストユーザー」に追加。
   - テスト状態のままだと認可が **7日で失効**します。個人利用なら「公開ステータス」を **本番環境** にしてください(審査なしで使えます。「未確認のアプリ」警告が出ますが自分のアプリなので「続行」で可)。
4. 「認証情報 → 認証情報を作成 → OAuth クライアント ID」
   - アプリケーションの種類: **Chrome 拡張機能**
   - アイテムID: `nkdgcnlckgfepbaadamalcdjdlajageh`
5. 発行された「クライアント ID」を `manifest.json` の `oauth2.client_id` に貼り付け
6. `chrome://extensions` → デベロッパーモードON → 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択
7. スプレッドシートを開き、ウィンドウの「Googleでログイン」を押して許可

> ログインしなくてもタブの全面塗りは動きます。シート一覧が必要な操作のみ認可が必要です。

> **アカウントについて**: `chrome.identity.getAuthToken` は **Chrome にログインしているプロフィールのアカウント**で認可します。スプレッドシートを別の Google アカウント(`/spreadsheets/u/1/...` など)で開いている場合、そのアカウントにファイルの権限が無いと「アクセスできません / 見つかりません」と表示されます。Chrome 以外の Chromium 系ブラウザ(Edge など)では `getAuthToken` が使えない場合があります。Chrome 116 以降が必要です。

## 使い方

| 操作 | 方法 |
|---|---|
| シートを選択 | 行をクリック(純正タブのクリックを再現して切り替え、効かなければURLの `#gid=` で切り替え。切替後はキー入力が表側へ戻る) |
| 非表示シートを開く | 行をクリック → 自動で一時表示(処理中は行が点滅、完了後「一時」バッジ・点線枠)。別のシートへ移動 / タブを閉じる / 再読み込み / ブラウザ終了で自動的に非表示へ戻る |
| 常に表示 / 非表示 | 行の目アイコン(一時表示中にクリックすると「常に表示」に確定) |
| 並び替え | 行右端の「⋮⋮」をドラッグ(Escでキャンセル、端でオートスクロール)。キーボードでは行を選んで `Alt+↑/↓` |
| 名前変更 | 名前をダブルクリック or `F2` |
| 右クリックメニュー | 表示中シートは**純正タブのメニューをそのまま**表示。非表示シートは同等の項目を自前メニューで表示 |
| 複数選択 | チェックボックス(Shift+クリックで範囲選択) → コピー / 削除 / 表示 / 非表示 / 色。コピーは元が非表示でも**表示状態**で作られます |
| 絞り込み | 検索欄(シート名)+ 色チップ(そのブックで使用中の色から選択・複数可) |
| 色ごと一括選択 | 色で絞り込み → 「全選択」(絞り込み結果のみ対象) |
| ウィンドウ | ヘッダーをドラッグで移動、右下でリサイズ、ダブルクリック/「–」で最小化、「×」で閉じる(右端の「シート一覧」タブで再表示)。右寄せで置いたウィンドウはブラウザの幅が変わっても右寄せのまま |

### ショートカット
- `Alt+Shift+W` … ウィンドウの開閉 / `Alt+Shift+K` … 検索欄へ移動
  - v1.0 の `Alt+Shift+F` は Docs/Sheets のメニュー用ショートカット(ファイルメニュー)と衝突するため変更しました。既定キーの変更は**新規インストール時のみ**反映されるので、更新した場合は `chrome://extensions/shortcuts` で付け直してください。
- 変更は `chrome://extensions/shortcuts`。拡張機能アイコンのクリックでも開閉。
- ウィンドウ内: `/` 検索 / `Ctrl+A` 全選択 / `Delete` 削除 / `F2` 名前変更 / `Esc` 解除
- 行の操作: `↑/↓` 移動 / `Enter` 開く / `Space` 選択 / `Alt+↑/↓` 並び替え / `Shift+F10` メニュー
- `Ctrl+Alt+D` … 診断情報をコピー(シートが切り替わらない等の調査用)
- ウィンドウ内のキー入力・日本語入力(IME)はスプレッドシート本体へ渡しません。

## 仕様上の注意
- 一時表示は共同編集中の他のユーザーにも見えます(個人用ファイル向け)。
- 一時表示は次の順で非表示へ戻します: 別シートへ移動 → タブを閉じる/リロード(バックグラウンドへのポート切断を検知。保険として `pagehide` でも通知)→ 次にそのブックを開いた時 → ブラウザ起動時 / 拡張機能の更新時。ネットワーク切断中は戻せないため、後の段階に持ち越されます。
- 一時表示中だけ、タブの終了を検知するためにバックグラウンド(service worker)を起こしたままにします(20秒ごとの ping)。
- 同じブックを複数タブで開いた場合、他のタブが一時表示中のシートは起動時の救済処理で戻しません。
- 一時表示を戻すと表示シートが1枚も無くなる場合(他を全部非表示にした等)、そのシートは表示のまま(常に表示)になります。
- 削除は元に戻せません(版の履歴からは復元可)。最後の表示シートは削除・非表示にできません(一時表示中のシートは「非表示」として数えます)。
- 色の「色なし」は `tabColor` / `tabColorStyle` の両方をクリアします。テーマ色のタブ色はブックのテーマから色を解決して表示します。
- 並び替えは Sheets API の `updateSheetProperties` の `index` を使います。右方向へ動かすときの `index` の解釈(移動元を除く前/後)が公式ドキュメントで明確でないため、移動後に読み直して位置がずれていれば補正します(API 呼び出しが最大4回)。

### Google スプレッドシートの画面構造への依存(不確実な点)
純正画面のDOMは非公開で予告なく変わるため、以下は推測に基づき、複数の手がかりでフォールバックしています。動かなくなった場合はここを確認してください。
- タブ要素: `.docs-sheet-tab`(無ければ `id="sheet-button-…"` の要素、さらに無ければクラス名に `docs-sheet-tab` を含む要素)。タブ名は `.docs-sheet-tab-name`、色は `.docs-sheet-tab-color` の背景色(または下線色)。
- タブとシートの対応: 要素ID `sheet-button-<gid>` があればそれを使い、無ければ**タブ名とシート名の一致**、それでも無理なら**表示中タブの並び順と API の表示中シートの順番**(枚数が一致する場合のみ)で対応付けます。
- 選択中のシート: `.docs-sheet-active-tab`(無ければ `aria-selected="true"`、さらに無ければ URL の `gid`)。
- シートの切り替え: 次の手段を順に試し、各手段のあと 700ms 以内に**純正側の選択中タブが目的のシートに変わったか**を確認します(最大8秒)。成功した手段は覚えておき、次回はそれから試します。
  1. タブ上で実際にポインターが当たる要素(ヒットテスト)へ、純正クリックと同じイベント列(pointerover → mouseover → pointermove → pointerdown/mousedown(buttons=1)→ pointerup/mouseup → click)を座標付きで送る
  2. 同じイベント列を `.docs-sheet-tab-name` へ  3. タブ要素そのものへ
  4. `location.replace` で URL の `#gid=` を変更  5. `location.hash` 代入 + `hashchange` 発火  6. `history.pushState` + `popstate`/`hashchange` 発火
  - 合成イベント(`isTrusted=false`)を Google 側が無視する場合はクリック手段が効かず、URL 系の手段が実機で効くかは**未確認**です。
- 切替に失敗したとき: パネル下部に原因(「タブ要素が画面に見つかりません」「このシートに対応するタブが見つかりません」「クリックを再現しても切り替わりませんでした」「タブが見つからず切替を確認できません」)を表示し、DevTools のコンソールに `[SheetTabManager]` で診断情報(タブの id/class/role/名前/位置/子要素、対応付け結果と方法、試した手段)を出します。パネル内で **`Ctrl+Alt+D`** を押すと、同じ診断情報をクリップボードへコピーします(不具合報告に貼ってください)。手段ごとの経過はコンソールの「詳細(Verbose)」レベルで見られます。
- 切替後のキー入力の戻し先: `iframe.docs-texteventtarget-iframe`(見つからなければパネルからフォーカスを外すだけ)。
- 右クリックの転送: 純正メニューは純正タブの位置付近に出る場合があります(表示位置は Google 側の実装次第)。
- ウィンドウ内の入力を本体に奪われないよう、コンテンツスクリプトを `document_start` で読み込み、ページより先にキーボード系イベントのリスナーを登録しています。
